# QILSRP Front End

Front end for the Queensland Indigenous Land and Sea Rangers Platform, built with React and Vite.

## Pages

- `/login` — Login screen
- `/register` — Account setup form
- `/dashboard` — Main dashboard

## Getting Started

Make sure you have [Node.js](https://nodejs.org) installed.

**Install dependencies:**
```bash
npm install
```

**Run the dev server:**
```bash
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

## Notes

- Any username and password will log you in for now
- Login session is stored in sessionStorage
- Backend integration to be added later
